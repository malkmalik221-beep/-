# POS System (نظام نقاط البيع) - pos_01

## نظام متكامل لإدارة نقاط البيع

### الميزات الرئيسية:
- ✅ إدارة المنتجات والفئات
- ✅ نقاط البيع والفواتير
- ✅ إدارة المخزون
- ✅ تقارير المبيعات
- ✅ إدارة المستخدمين
- ✅ نظام الخصومات
- ✅ إدارة الدفع

### التكنولوجيا المستخدمة:
- **Frontend**: React + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: MongoDB
- **Authentication**: JWT

### البنية الأساسية:
```
pos_01/
├── backend/          # خادم Node.js
├── frontend/         # تطبيق React
├── database/         # سكريبتات قاعدة البيانات
└── docs/            # التوثيق
```

## البدء السريع

### المتطلبات:
- Node.js v14+
- MongoDB
- npm أو yarn

### التثبيت:
```bash
# تثبيت الـ Backend
cd backend
npm install

# تثبيت الـ Frontend
cd ../frontend
npm install
```

### التشغيل:
```bash
# Backend
cd backend
npm start

# Frontend (في نافذة أخرى)
cd frontend
npm start
```
